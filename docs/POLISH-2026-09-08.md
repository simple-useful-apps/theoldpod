# Library polish acceptance — September 8, 2026

## Delivered

- Shared Library Status popover: iCloud Drive versus On This Device, latest completed index check time, cloud-only file count, manual Refresh Library, and an expandable folder location.
- iPhone pull-to-refresh on library browsers. Refresh rechecks the current watcher and reconciles playlist files; it does not claim to force iCloud delivery from another device.
- Refresh read errors are shown without replacing the last good local snapshot. Index save failures do not advance the check timestamp.
- Matching blue accents on iPhone and Mac: clearer blue in light appearance and a lighter blue for dark appearance.
- Plus icons for Add Music, New Playlist, and Import Book. Mac Books has only its contextual Import Book button, not two adjacent plus buttons.
- Search for artists, albums (including artist names), playlist names, and book titles. Existing song search remains. Mac artist/album search also narrows the adjacent song table.
- Native no-results feedback; no added tab animations.

## Verification

Both final apps build successfully with `make ios` and `make mac`. `git diff --check` passes. No unit tests were run.

Computer-use checks used isolated acceptance libraries, never the user's shared iCloud library:

- Mac: manual refresh advanced the displayed timestamp; final popover text wraps correctly. Artist and album search narrowed both their lists and song tables, with no-results feedback. Playlist name search narrowed the sidebar. Books search displayed no-results feedback. Final Books toolbar has one plus button.
- iPhone 17 simulator: manual refresh advanced the timestamp. Artists, Albums, Playlists, and Books each showed search; matching queries restored results after nonmatching queries. Album search matched artist names. Songs, Playlists, and Books used matching plus controls. Final compact status popover inspected after reinstall.
- Both apps retained paused audiobook state during verification.

Not verified here: real-device iCloud transfer, cloud-only status count, injected storage/read failures, pull-to-refresh gesture completion, VoiceOver/Dynamic Type, or visual dark-mode acceptance. These are not implied by the successful local checks.

## Short manual follow-up

1. On both devices, open Library Status. Confirm it says iCloud Drive for the intended shared library, rather than On This Device.
2. Import music or a book through the normal app. On the other device, choose Refresh Library and confirm the check time advances. Allow iCloud time to transfer files; refresh is not a transfer guarantee.
3. Search every section with a matching name, an impossible name, then clear it. Results should return immediately, without affecting playback.
4. Check the blue controls in light and dark appearance. Try larger text and ensure the status explanation and Refresh Library button remain readable.
